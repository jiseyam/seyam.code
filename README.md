# seyam.code

> Modern, immersive 3D developer portfolio for **Jihadul Islam Seyam** — Full-Stack Engineer, Flutter & Software Developer.

## 🚀 Built With

- **React 18** & **TypeScript**
- **Tailwind CSS** (Custom dark luxury aesthetic)
- **Framer Motion** (Smooth gesture physics, directional scroll reveals, auto-hiding navigation)
- **Lucide React**
- **Web3Forms API** (Direct email messaging service)
- **Vite**

## 🌟 Key Features

- **Cyber-Monochrome Dark Theme**: Built around `#0C0C0C` background, `#D7E2EA` metallic platinum accents, and Kanit typography.
- **Smart Auto-Hiding Navbar**: Automatically detects scroll velocity and direction to hide on scroll-down and reveal smoothly on scroll-up.
- **Interactive Project Showcase**: Infinite horizontal marquee displaying real, running application screenshots.
- **Sticky Project Cards**: Smooth stacking interaction driven by Framer Motion scroll progress.
- **Direct Messaging Hub**: Direct email delivery using Web3Forms with real-time status banners and validation.

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
